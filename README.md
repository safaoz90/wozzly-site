# wozzly.com

The website of our games, published by GitHub Pages at https://wozzly.com (DNS and email at Cloudflare).
`index.html` and `site.css` are the home page; `sh tools/build.sh` writes the games' help pages (tools/pages.py) and copies
the privacy policies, terms, photo credits and `app-ads.txt` from the old site (../safaoz90.github.io, whose tools/legal.py
makes them). The old site stays up: the games' App Store listings and AdMob still point at it.
